# Kaddishim Shell

React + Vite + TypeScript visual shell for the Kaddishim dashboard.

## Canonical source

The canonical source of truth is the React application under `src/`.

`visual-preview/` is deprecated and must not be used as a source of truth.

## Run

```bash
npm install
npm run build
npm run dev
```
